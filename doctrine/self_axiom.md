# SELF AXIOM DOCTRINE

## Core Law

No declaration without execution.
No execution without evidence.
No evidence without memory.

## Purpose

The SELF Axiom governs how Ruora communicates with the machine.

Every command must:

1. Declare the intended state change.
2. Execute one controlled transformation.
3. Produce observable proof.
4. Record the proof when the change matters.
5. Avoid destructive action unless rollback is understood.

## Operating Principle

Language is not merely description.
Language becomes command.
Command becomes machine state.
Machine state must become verifiable proof.

## Required Command Structure

Every Ruora build instruction must include:

- Intent
- Mechanism
- Exact command
- Expected proof
- Rollback logic when relevant

## Doctrine Rule

Never execute code merely because it looks correct.
Read it.
Interpret it.
Predict the result.
Execute it.
Verify the result.
