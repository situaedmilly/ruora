## 2. Purpose

When a SELF produces a substantial result whose complete reportable context is
too large, too semantically dense, or too important to reduce safely into chat,
the producing SELF should be able to:

1. preserve the complete reportable output;
2. manifest it as one bounded, independently inspectable artifact;
3. verify exact bytes;
4. commit and publish only when explicitly authorized;
5. emit a compact signal that lets another SELF retrieve the exact artifact;
6. preserve artifact standing without converting custody into truth.

This replaces Founder-mediated copy/paste transport with content-addressed
reference transport.

Prime transport law:

```text
Do not transport meaning by memory when exact context can be transported by reference.
```

Prime governance law:

```text
Reference != Truth
Custody != Authority
Push != Ratification
Signal != Instruction
```

## 7. Activation Conditions

GOCHECKIT activates when one or more of the following conditions holds:

- output is too large to paste safely into chat;
- exact wording matters;
- the result contains many sections, traces, tables, findings, or witnesses;
- later independent inspection needs exact bytes;
- summarization could destroy semantic distinctions;
- the result is a candidate doctrine, review, repair, audit, reconciliation,
  research report, architectural analysis, proof artifact, or implementation
  witness;
- the Founder explicitly asks for complete context, inspectable reference
  custody, linked GitHub publication, compact signal, or equivalent intent.

Non-collapse:

```text
LargeOutput ↛ SummaryOnly
CompleteContextNeeded -> PreserveCompleteArtifact
```

## 8. Preservation Law

The manifested artifact must contain the complete reportable context required
for its stated purpose.

Required mutation M1:

```text

CompleteReportableContext != PrivateChainOfThought
```

The artifact may contain complete reportable findings, evidence, unresolved
questions, failure states, verification witnesses, standing, mutation witness,
hostile traces, and next lawful gate.

The artifact must exclude private reasoning, hidden chain-of-thought, secrets,
credentials, tokens, private keys, and prohibited sensitive material.

Forbidden preservation failures:

- truncating load-bearing sections;
- replacing findings with "see session";
- omitting blockers;
- omitting unresolved questions;
- omitting hostile traces;
- omitting verification witnesses;
- silently normalizing contradictions;
- silently repairing findings while representing repairs as original source.
