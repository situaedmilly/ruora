## 0. Recording-runtime disclosure

This entry is written by **CLAUDESELF**, not by the runtime of origin.

The authorizing command declared `RUNTIME: CODEXSELF`. The runtime that
actually executed it is CLAUDESELF (Claude Code session, working from the
ACTIMANIRUN implementation host). That difference is recorded first, because
every downstream claim inherits it.

```text

```

This runtime did **not** observe the CodexSELF session. It received a Founder
transcription of a quoted string. That is an admissible intake path for this


governance event.
