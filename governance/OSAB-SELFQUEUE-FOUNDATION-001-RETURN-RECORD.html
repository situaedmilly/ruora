Findings ledger

BLOCKING F-01 · OSAB realization regress — who boots OSAB?

The command declares OSAB ≠ Claude ≠ Codex ≠ GPT, but names no realization for OSAB itself. Today, every act attributed to OSAB — admission, boot witness, authority binding — would be performed by a prompted model session wearing an OSAB label. That is UNGOVERNED_SELF_INSTANTIATION reproduced one level up: the boot witness would be narrative, and the whole structure inherits self-attestation at its root.

Repair: bind OSAB's v0 realization to the deterministic control plane, not to a session. The precedent already exists on disk: router/sia-registry.js is data + validation only, deep-frozen, fail-closed, never executes. OSAB v0 = schema + validator + append-only queue records + a witness-emitting instrument. A session may operate the instrument; it may not be the witness.

BLOCKING F-02 · HBCSELF referent collision with ratified doctrine

SELFHTML-HBC-LINEAGE-ADOPTION-001-DOCTRINE (ratified, on disk) defines HBCSELF as the Founder's lineage designation for the existing HBC system — the Hyperbolic Build Chamber compiler at ~/RUORA/projects/hbc-html — and explicitly holds that no document may make HBC a SELF "until a later identity gate deliberately reconciles it." The foundation command redefines HBCSELF as an instantiable hostile-reviewer role constitution (HBCSELF#001…#003 across providers). Two incompatible referents; adopting the command as written would silently pre-adjudicate the deferred identity gate.

Repair (Founder's choice): either (a) name the hostile-reviewer role something unclaimed — e.g. HOSTILEREVIEWSELF — and let HBC review remain a mission it can be given, or (b) run the deferred HBC identity gate first and let its outcome settle the referent. Do not let the foundation command decide this as a side effect.

BLOCKING F-03 · Independence predicates are not observable by any instrument

Section 7's checklist includes predicates no instrument on this machine can evaluate for a third-party runtime: "does it inherit author-private reasoning," "was it instructed toward a preferred result." If the law admits these as required inputs without classing them, the independence verdict is once again produced by narrative — the exact failure this gate exists to close.

Repair: class every predicate as OBSERVABLE_BY_INSTRUMENT (same session id, subject digest match, runtime's prior mutation of subject via recorded lineage), ATTESTABLE_BY_FOUNDER (what was pasted where), or UNOBSERVABLE. Fail closed: any required predicate left UNOBSERVABLE caps the verdict at INDEPENDENCE_PARTIAL. INDEPENDENCE_ESTABLISHED becomes reachable only through instrument-observed plus Founder-attested predicates.

MATERIAL F-04 · Ensemble quorum contradicts NO_CONSENSUS_LAUNDERING

The example queue record carries minimum_valid_returns: 2 while the closing command demands aggregation = NO_CONSENSUS_LAUNDERING. A 2-of-3 quorum is a consensus mechanism if agreement promotes a verdict.

Repair: state the aggregation law explicitly — instance verdicts are never merged, averaged, or vote-counted; each return stands alone in DATASELF; only the Founder (or a separately constituted adjudication gate) disposes across them. minimum_valid_returns may govern sufficiency to close the request, never truth of the verdict.

MATERIAL F-05 · "OSAB" is an unrecorded naming act

OSAB has zero real occurrences on disk (one hit is a base64 substring in an evidence blob). The ratified naming layer records the execution layer as OURSELFAGENTBRIDGE; the workflow stack self-identifies as OURSELF-AGENTBRIDGE-WORKFLOW-v0.1. The packet warns against two abbreviations becoming two identities while itself introducing a second alias (ABOS) — and the ecosystem already carries one live naming drift (the INTITUSELF bot misspelling, never fixed).

Repair: one recorded naming act in the naming layer: canonical name, canonical shorthand, alias standing (historical only), and where each may appear. Until then OSAB is conversational shorthand, not identity.

MATERIAL F-06 · HTMLSELF#001 example collapses a system constitution into an operator role

Section 5 lists HTMLSELF#001 as an instance example. HTMLSELF is a system's identity under the freshly ratified HTMLSELF/ResearchSELF identity law — a constitution to be governed, not an operator role to be instantiated N times. The example quietly reverses a distinction ratified this very day.

Repair: remove the example and add the distinction to the law: role constitutions (operators; instantiable) vs system constitutions (artifacts/systems; never instantiable through SELFQUEUE).

MATERIAL F-07 · Queue state machine is incomplete and unreconciled with the revocation track

The eleven states lack DENIED (admission refused — distinct from FAILED), REVOKED (admission withdrawn after grant), and EXPIRED (TTL lapse without return). "No state may be skipped silently" is unenforceable without a legal-transition table. An entire ADMISSION-REVOCATION-CHANNEL-01 design track already exists in the control plane's DESIGN corpus (R01 returned CHANGES_REQUIRED; R02 repair queued) — SELFQUEUE revocation must reconcile with it, not fork it.

Repair: add the three states, author the transition table as part of the schema, and cite ADMISSION-REVOCATION-CHANNEL-01 as the controlling revocation design.

MATERIAL F-08 · Missing bindings: trusted time, causal parent, quiescence

DATASELF events require timestamps, but TRUSTED-TIME-SOURCE-01 is still an open disposition candidate in the DESIGN corpus. The SELFBOOT request schema carries no causal_parent_ref / supersedes_ref — the exact fields whose absence produced the SFC-005 constitutional fork (the founder-decision-record problem). And queue records are mutable governed state, so writes fall under the ratified scoped-quiescence law.

Repair: add causal_parent_ref, supersedes_ref, time_source_ref, and a quiescence_witness obligation for queue mutations; bind timestamps to whatever TRUSTED-TIME-SOURCE-01 resolves to.

MINOR F-09 · DATASELF / OBSERVERSELF standing and the observer's own bootstrap

The Memory Organ doctrine that defines DATASELF is RESEARCH/DEFERRED — not adopted. And OBSERVERSELF has a witness regress: who observes the observer's boot? Both are resolvable without the organs.

Repair: v0 observer = a mechanical evidence instrument (the selfgraph-witness pattern: digests, diffs, process state — no narrative authority); v0 DATASELF = the existing governance/evidence/ chamber pattern (append-only JSONL). Mark organ-level language DESIGN_PENDING_ADOPTION.

3 · The exact gap the HTMLSELF incident exposed

The stack can admit a command and situate a session, but owns no object binding role constitution + instance identity + authority envelope + boot witness + lifetime. The sharper mechanism failure sits inside the fixture itself: HTMLSELF-v0.1-HBC-REVIEW-PACKET-001 §3 hands the independence gate to the reviewer — the candidate runtime is asked to attest its own independence. Self-attestation was the only mechanism available, so the only lawful move for an honest runtime was the STOP it produced. The packet's fail-closed clause worked exactly as designed; what is missing is a party other than the candidate that can produce the verdict. That is the seat SELFQUEUE admission fills.

End question

Before a runtime can lawfully say "I am HBCSELF#001", OSAB must hold a ratified role constitution with a settled referent; an admitted, digest-bound request with causal parent; a bound authority envelope and jurisdiction; an independence verdict produced at admission, from classed predicates, by a party that is not the candidate; a boot witness written by an instrument; an observer record; and an open lifetime with defined termination.

But the structural answer is smaller than the list: under the three-axis law, "I am HBCSELF#001" is never a sentence the runtime is entitled to author. It is an Observed-class fact that only the queue's instrument may write, and the runtime may at most read back. A model session prompted to act like HBCSELF can produce the same words — it can never produce the record. The record is the identity.
