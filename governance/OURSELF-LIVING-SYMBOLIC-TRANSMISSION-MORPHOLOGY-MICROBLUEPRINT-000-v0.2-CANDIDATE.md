## 10. OCCURRENCE INDIVIDUATION (F-10 REPAIR)

### 10.1 General identity law

An occurrence's identity is fixed at minting by:
`(species, generative-act ref, performing-context ref, subject/content refs,
TG4R birth-edge ref)`. Once minted, identity is immutable; repair happens by
appending descendants, never editing (per estate ratification-binds-evidence
discipline).

Universal relations (all TG4R-custodied):

```
REPLAY:        new occurrence + replay_of      (same referenced matter, new act)
RETRY:         new occurrence + retry_of       (same intent, after failure)
CONTINUATION:  new occurrence + continuation_of (advances unfinished course)
PROJECTION:    mints NOTHING (a read of LMG/TG4R is not an occurrence;
               it becomes one only if constituted as an ObservationAct)
DESCENT:       any content transformation mints a descendant + derived_from
```

### 10.2 Per-species criteria

| Species | New occurrence when… | Identity preserved under… | Necessarily a descendant when… |
|---|---|---|---|
| RepresentationOccurrence | an act binds content to addressed Matter (re-authoring identical content = new occurrence — new act) | custody copy / storage move (CustodyCopy != NewRepresentation) | content transformed (projection, compression, translation…) |
| EmissionOccurrence | an act releases a representation beyond its forming context; each release is new | transport buffering | re-emission = new emission with replay_of |
| SignalOccurrence (DERIVED_COMPOSITE — §13.2) | exactly one per EmissionOccurrence, binding SymbolRef/RepresentationRef + emission + source context | nothing — it is 1:1 with its emission | never — descendants attach to the representation or emission |
| TransmissionOccurrence | per traversal attempt per route (PUSH); per availability-establishment (PULL) | retransmission at transport layer within one attempt | route change = new occurrence |
| DeliveryOccurrence | PUSH: arrival at receiver boundary; PULL: availability established toward a nodefield | repeated identical availability announcements | re-delivery after revocation = new occurrence |
| ReceiptOccurrence | bytes/event enter a receiver's custody; each independent retrieval = new receipt | re-reading within unchanged custody (no new receipt) | receipt into a different SELF's custody = distinct receipt, always |
| SituationOccurrence | per binding attempt of a received occurrence against the receiver's reality; a re-attempt after the receiver's reality changed = new occurrence (continuation_of or retry_of) | re-inspection without re-binding | outcome-changing re-situation |
| TreatmentOccurrence | per treatment act applied to a situated occurrence | — | chained treatments reference predecessors |
| MorphOccurrence | per qualified (MORPH_CANDIDATE) and, where required, authorized reality transition; NO_MORPH mints a qualification record, NOT a MorphOccurrence | — | rollback/counter-morph = new MorphOccurrence referencing the first |
| ConsequenceOccurrence | per witnessed downstream distinction attributable via TG4R | re-witnessing an unchanged consequence | — |
